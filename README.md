# 📈 Análisis de Precios de Acciones de NVIDIA, AMD e Intel (2004-2024)

## 🚀 Descripción del Proyecto
Este proyecto analiza el comportamiento histórico de las acciones de los tres gigantes de GPUs (NVIDIA, AMD e Intel) desde 2004 hasta 2024. ¡Descubre cómo los lanzamientos tecnológicos y eventos globales impactan el mercado financiero! 💹🔍

## 🎯 Objetivos
- **Principal:** Identificar patrones entre innovaciones tecnológicas 📱💻 y movimientos en los precios de acciones
- **Específicos:**
  - 📂 Consolidar datos históricos de 20 años
  - 📊 Visualizar tendencias comparativas
  - 🧠 Analizar impacto de crisis económicas 🌍💸

## 📂 Dataset
- **Fuente:** [Kaggle](https://www.kaggle.com/datasets/kapturovalexander/nvidia-amd-intel-asus-msi-share-prices) 
- **Datos incluidos:**
  - 💰 Precios diarios (apertura, cierre, máximos, mínimos)
  - 📊 Volumen de negociación
  - 🎉 Eventos tecnológicos clave

## ⚙️ Metodología
1. **🧹 ETL:** Limpieza de datos con Pandas
2. **📈 Análisis:**
   - Correlaciones estadísticas
   - Modelado de series temporales
3. **📊 Visualización:**
   - Gráficos interactivos
   - Dashboards completos

## 💻 Tecnologías Utilizadas
| Categoría | Herramientas |
|-----------|-------------|
| **Lenguaje** | Python 3.9+ 🐍 |
| **Librerías** | pandas, numpy, matplotlib, seaborn, statsmodels |
| **Visualización** | Plotly, Matplotlib |

## 🔍 Resultados Clave
- **NVIDIA** 🟢: Saltos significativos con lanzamientos de arquitecturas RTX.
- **AMD** 🔴: Gran recuperación post-2016 con Ryzen/EPYC.
- **Intel** 🔵: Caídas por retrasos en fabricación.
